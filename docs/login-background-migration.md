# 统一登录背景插件迁移

`org.lux.bing-daily-background` 与 `org.lux.tmdb-trending-background` 已由
`org.lux.login-background` 取代。新版插件提供 Bing 每日图、TMDb 日榜和单张自定义上传图三种来源。

## 在 Lux 中迁移

1. 从 Lux 插件商店安装并启用 `统一登录背景`。
2. 打开插件配置，选择原来使用的来源：`必应每日图片` 或 `TMDb 日榜电影与剧集横幅`。
3. 重新逐项确认对应许可。旧插件的许可确认不会迁移：Bing 个人用途确认与 TMDb 非商业许可确认相互独立，默认均关闭。
4. 若使用自定义图，上传一张 JPEG、PNG 或 WebP，再单独确认拥有将该图用于登录页公开展示的权利。上传新图会替换旧图。
5. 保存配置，在服务器设置中将登录背景来源切换为统一插件，检查未登录页面显示正常。
6. 确认新来源工作后，在 Lux 的已安装插件管理中手动卸载旧 Bing/TMDb 背景插件。

登录背景对未登录访问者公开。不要上传你没有权利公开展示的图片。图片不会自动压缩或重编码；文件上限为 5 MiB、20 MP。

## 旧包说明

旧插件不再出现在官方活动目录，旧 Release/tag 与其 ZIP 包会在统一插件发布成功后移除。已有 Lux 实例中的旧插件不会被远程卸载；请先完成上述切换并验证，再手动卸载。旧配置与旧许可确认不会复制到新插件。
